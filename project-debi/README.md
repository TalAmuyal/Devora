# Devora

Debi is Devora's CLI for workspace management and utilities.
It provides the `debi` commands (PR submission, multi-repo git, health checks, …) that the Devora app and its terminal sessions call into.

## Building

```bash
mise build
```

This produces the `debi` binary.

## Testing

```bash
mise test
```
